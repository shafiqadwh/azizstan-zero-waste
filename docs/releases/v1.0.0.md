## ระบบประเมินความสะอาด
- **กรรมการ**: งานของฉัน, ฟอร์มประเมินพร้อมรูปหลักฐานและใบลงชื่อ, แก้ไขเองได้ในเวลาที่กำหนด, คำขออนุมัติ 6 แบบ
  (ขอลงคะแนนเกินเวลา แก้คะแนน แก้รูป แก้ข้อติชม ย้ายเป้าหมาย ลบ)
- **ใช้ได้แม้สัญญาณอ่อน**: ร่างเก็บในเครื่อง ส่งเองเมื่อมีสัญญาณ (ร่างถูกลบเมื่อส่งสำเร็จ เมื่อเกิน 7 วัน และเมื่อออกจากระบบ)
- **QR ที่ประตูห้อง**: เปิดหน้าของห้อง → เมนู "ประเมินความสะอาด" (เตรียมไว้รวมระบบแจ้งปัญหาไอที/อาคารในอนาคต)
- **แอดมิน**: ภาพรวม, อนุมัติผล (คีย์ลัด), ติดตามสถานะแบบแผนผัง, ปิดรอบ, PDF ทั้งรอบในไฟล์เดียว,
  เช็กลิสต์ตั้งค่าเริ่มต้น 9 ขั้น, อนุมัติอัตโนมัติ (เลือกเปิดได้ต่อภาคเรียน)
- **รูปแบบการประเมิน**: รายห้อง/รายอาคาร/รายโซน, แบบกลุ่มหรือรายบุคคล (แสดงเฉพาะรหัสนักเรียน), ครูประจำพื้นที่หักคะแนน
  (ปิดไว้ปีนี้)
- **เอกสาร PDF**: แบบรายงานผลหน้าเดียว ฟอนต์ Sarabun, ใบลงชื่อเปล่า, แผ่น QR ห้อง A4 ละ 12 ห้อง, คำสั่งแต่งตั้ง
- **หน้าสาธารณะ**: หน้าแรก, จัดอันดับ, คะแนนรายห้อง/รายพื้นที่, กราฟพัฒนาการ, ปฏิทินรอบ, คำสั่ง, คู่มือ
- **การแจ้งเตือน**: กล่องแจ้งเตือนในระบบ + แจ้งเตือนบนมือถือ (PWA), เตือนก่อนปิดรอบและเมื่อเลยกำหนด
- **เชื่อมต่อ**: ซิงก์รายชื่อนักเรียนทุกคืน, API สำหรับโปรแกรม ปพ.5 (จำกัด IP), ส่งออก Excel

## ความปลอดภัยและการดูแลระบบ
- ไม่เก็บเลขบัตรประชาชน วันเกิด ชื่อผู้ปกครอง เบอร์โทร และไม่แสดงชื่อนักเรียนบนหน้าจอใด
- CSP + security headers, ป้องกัน CSRF, จำกัดอัตราการเรียก, ยืนยันรหัสผ่านซ้ำก่อนแก้สิทธิ์ผู้ใช้, บันทึกการทำรายการแก้ไขไม่ได้
- เก็บข้อมูลภาคเรียน 1 ปีหลังปิดภาค แล้วลบอัตโนมัติ (เตือนล่วงหน้า 30 วัน ดาวน์โหลดเก็บถาวรได้)
- สำรองข้อมูลเข้ารหัสทุกคืนออกนอกเครื่อง, ขั้นตอนกู้คืนผ่านการซ้อมจริงแล้ว
- ตรวจความพร้อมก่อนขึ้นระบบ (preflight), เตือนแอดมินเมื่อดิสก์ใช้เกิน 80%

## ผลการทดสอบของเวอร์ชันนี้
- unit 659 · ฐานข้อมูล 190+ · e2e 110 (มือถือ 360px และจอ 1440px)
- ทดลองติดตั้งจาก Docker image จริง: e2e ผ่านกับ container, สร้าง PDF ภาษาไทยได้, สำรอง → ลบทั้งหมด → กู้คืน ข้อมูลครบ

## ยังไม่รวมในเวอร์ชันนี้
- ล็อกอินด้วยบัญชีครูของโรงเรียน (T33) — รอสเปก API ตอนนี้ใช้บัญชีในระบบ
- หัวหน้าโซนและทีมครูประจำโซน (T42) — พักไว้ตามมติ
- ระบบแจ้งปัญหาไอทีและอาคารสถานที่ — เฟสถัดไป ใช้ QR ห้องเดียวกัน

## ต้องทำก่อนเปิดใช้จริง
- เปลี่ยน token ของ API รายชื่อนักเรียน แล้วใส่ใน `.env`
- preflight ต้องไม่มี `✗` และต้องซ้อมกู้คืนข้อมูลแล้ว (ดูเช็กลิสต์ท้าย `docs/go-live-th.md`)
